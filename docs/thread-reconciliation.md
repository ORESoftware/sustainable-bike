# Thread reconciliation

This repository resumes the sustainable-bicycle request from the August 21, 2026 conversation and incorporates the follow-up constraints:

- one chainring;
- internal rear gears/cogs;
- no derailleur;
- no manual gear switching;
- a non-metallic aramid/Kevlar-class belt with no lubrication;
- single-sided front and rear support;
- captive wheel retention rather than quick-release wheels;
- solid or very puncture-resistant tires;
- a small rear-hub motor; and
- a 25 mph flat-ground assist target.

The literal “wheel and frame are one part” wording was resolved as a mechanically captive wheel cartridge because a rigid one-piece wheel/frame cannot rotate. The CAD and architecture record preserve the anti-theft goal while making this kinematic constraint explicit.

Unrelated unfinished ChatGPT project threads are not silently mutated from this repository. Cross-project work should retain its own repository, issue, branch, authorization, and verification evidence so that changes remain auditable and do not contaminate this safety-critical design.
